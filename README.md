# Security Cars - Starter

This repository contains a simple web app skeleton with a Go backend (hexagonal architecture) and a React frontend.

## Backend (Go)

```bash
cd backend
go run ./cmd/server
```

The API exposes:

- `GET http://localhost:8080/api/health`

## Frontend (React)

```bash
cd frontend
npm install
npm run dev
```

Visit `http://localhost:5173` and click "Get backend greeting".
